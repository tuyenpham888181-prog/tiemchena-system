# Tiệm Chè Na - Hệ Thống Website Bán Chè & Thu Hút Lead (Day 4)

Website chính thức của **Tiệm Chè Na** phục vụ đặt món chè nhà nấu thanh mát, kèm cơ chế thu thập Data / Lead tự động qua Quà tặng Digital (Ebook Công Thức Chè Thanh Nhiệt) và Voucher giảm giá 20.000đ.

---

## 🌟 Tính Năng Nổi Bật Trên Website
1. **Hero & Giới Thiệu Thương Hiệu**: Nổi bật cam kết nguyên liệu loại 1, nấu tươi trong ngày, dùng 100% đường phèn thanh khiết.
2. **Menu Chọn Món Trực Quan**: Phân loại theo Chè Dưỡng Nhan, Chè Truyền Thống, Chè Khúc Bạch & Trái Cây; kèm giá niêm yết rõ ràng và nút đặt nhanh.
3. **Giỏ Hàng Tự Động & Đặt Hàng Thông Minh**: Tự động tính tiền và đổ danh sách món vào khung đặt hàng.
4. **Lead Capture & Digital Magnet (Mồi câu chuyển đổi)**: Form đăng ký nhận ngay **Voucher 20K** (`TIEMCHENA20K`) + Ebook PDF độc quyền.
5. **Live Social Proof**: Pop-up thông báo đơn hàng / lượt nhận voucher thời gian thực.
6. **Bảng Quản Lý Lead Tích Hợp (Admin Lead Viewer)**: Hiển thị ngay data khách đã đăng ký (Họ tên, SĐT, Địa chỉ, Ghi chú/Món đặt) với nút xuất file JSON/Excel để phục vụ nộp bài & đối soát.

---

## 🚀 Hướng Dẫn Kích Hoạt & Xem Website

### Cách 1: Chạy trực tiếp trên trình duyệt
Mở trực tiếp file `index.html` bằng trình duyệt (Chrome, Edge, Cốc Cốc...).

### Cách 2: Deploy lên GitHub Pages (Miễn phí 100%)
1. Push toàn bộ code lên repository:
   ```bash
   git add .
   git commit -m "feat: complete Tiem Che Na landing page and lead capture system for day 4"
   git push origin main
   ```
2. Vào GitHub: `Settings` -> `Pages` -> Chọn nhánh `main` / `root` -> `Save`.
3. Link live: `https://tuyenpham888181-prog.github.io/tiemchena-system/`
